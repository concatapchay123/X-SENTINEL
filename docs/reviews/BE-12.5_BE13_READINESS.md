# BE-12.5 TO BE-13 READINESS & HANDOFF CONTRACT

- **Project**: X-SENTINEL V3
- **Target Phase**: `PLAN-BE-13` (Jev AI API Endpoints, Audit Trail Persistence, Feedback & Telemetry)
- **Readiness Verdict**: **READY FOR BE-13**

---

## 1. Boundary Verification (`PLAN-BE-12` vs `PLAN-BE-13`)

Per `PLAN-BE-13.md`, `10_API_CONTRACT.md`, and `docs/api/jev_ai_openapi_fragment.yaml`:
- **No Premature BE-13 Route Implementation**: `backend/src/x_sentinel/api/routes.py` currently exposes only `GET /v1/ai/status` (implemented in `BE-03`). The `BE-13` execution, retrieval, and feedback endpoints (`POST /v1/ai/explain`, `GET /v1/ai/runs/{run_id}`, `POST /v1/ai/runs/{run_id}/feedback`) have **not** been prematurely added, respecting the strict scope boundary of `BE-12.5`.
- **Database Schema Readiness (`BE-02` / `07_DATABASE_SPEC.md`)**: `backend/src/x_sentinel/database/models.py` already defines `JevAIRun` (`__tablename__ = "jev_ai_runs"`) and `JevAIFeedback` (`__tablename__ = "jev_ai_feedback"`) with exact check constraints:
  - `jev_ai_mode_allowed`: `mode IN ('explain','triage','compare','report','docs')`
  - `jev_ai_status_allowed`: `status IN ('queued','running','completed','failed','blocked')`
  - `jev_ai_feedback_rating_allowed`: `rating IS NULL OR (rating >= 1 AND rating <= 5)`
  - `jev_ai_feedback_label_allowed`: `label IS NULL OR label IN ('helpful','not_helpful','incorrect','unsafe','unclear')`

## 2. Phase P2 — Storage Classification Table (`jev_ai_runs` & `jev_ai_feedback`)

| Data Element | Storage Classification | Persistence Target | Security / Privacy Rule |
| :--- | :---: | :--- | :--- |
| **`input_digest_sha256`** | **MUST STORE** | `jev_ai_runs.input_digest_sha256` (`String(64)`) | 64-char SHA-256 hex digest over RFC 8785 canonical safe context |
| **`output_digest_sha256`** | **MUST STORE** | `jev_ai_runs.output_digest_sha256` (`String(64)`) | 64-char SHA-256 hex digest over canonical workflow result |
| **`mode` / `status` / `model_id` / `prompt_version` / `latency_ms`** | **MUST STORE** | `jev_ai_runs` columns | Enforced by DB check constraints `jev_ai_mode_allowed` and `jev_ai_status_allowed` |
| **`context_summary` (Allowlisted Evidence Summary)** | **MUST STORE** | `jev_ai_runs.context_summary` (`JSON`) | Contains only allowlisted, redacted evidence (`ALLOWED_CONTEXT_KEYS`); zero raw PE or vectors |
| **`response_text` (Advisory Output / Markdown)** | **MUST STORE** | `jev_ai_runs.response_text` (`Text`) | Validated advisory output (`advisory_only=True`) |
| **`error_code` & Redacted `error_message`** | **MUST STORE (on failure/block)** | `jev_ai_runs.error_code`, `jev_ai_runs.error_message` | Mapped via `classify_jev_failure(exc)`; message redacted via `redact_sensitive_text()` |
| **Analyst `rating` (`1..5`), `label`, Redacted `comment`** | **MUST STORE (on feedback)** | `jev_ai_feedback` columns | Linked to `jev_ai_runs.id`; comment sanitized and redacted |
| **Raw Runtime Response JSON (`JevResponse.raw`)** | **EPHEMERAL DEFAULT (`store_raw=False`)** | Memory-only unless `XS_JEV_AI_STORE_RAW=true` | Never persisted in `jev_ai_runs` by default |
| **Raw PE Binaries, Byte Streams, Disassembly** | **FORBIDDEN TO STORE / SEND** |Blocked (`JevForbiddenKeyError`) | Blocked by `FORBIDDEN_KEYS` before context projection or DB persistence |
| **Full 2,381-Feature Vectors (`features`, `raw_vector`)** | **FORBIDDEN TO STORE / SEND** | Blocked (`JevForbiddenKeyError`) | Only `top_shap[:k]` (`k <= 20`) and `view_contributions` are permitted |
| **Blind Evaluation Ground Truth & Trigger Manifests** | **FORBIDDEN TO STORE / SEND** | Blocked (`JevBlindDataBlocked`) | All 12 `BLIND_DATA_KEYS` blocked in keys (including aliases) and free text |
| **API Keys, Passwords, Tokens, DB URLs, Private Host Paths** | **FORBIDDEN TO STORE / SEND** | Blocked / Redacted | Blocked in keys (`FORBIDDEN_KEYS`) and redacted in strings (`redact_sensitive_data`) |

## 3. Direct Mapping from BE-12 Orchestrator Outputs to `JevAIRun` (`jev_ai_runs`)

All four `JevAIOrchestrator` workflow return types (`ExplainResult`, `TriageResult`, `CompareResult`, `ReportResult`) and `TypedDecisionResponse` expose standardized BE-13 handoff fields that map 1-to-1 to `JevAIRun`:

| `JevAIRun` Column (`models.py`) | Orchestrator Result Field (`ExplainResult` / `TriageResult` / `CompareResult` / `ReportResult`) | Notes for BE-13 Persistence Service |
| :--- | :--- | :--- |
| `analysis_job_id` | `result.analysis_id` (UUID if resolved from `analysis_jobs.id`) | Nullable FK to `analysis_jobs.id` (`ondelete="SET NULL"`) |
| `requested_by_user_id` | From authenticated API caller context (or `None` in headless local mode) | Nullable FK to `users.id` |
| `mode` | `result.workflow` (`"explain"`, `"triage"`, `"compare"`, `"report"`) | Satisfies `jev_ai_mode_allowed` check constraint |
| `status` | `result.validation_status` (`"completed"`) or `classify_jev_failure(exc).db_status` (`"failed"`, `"blocked"`) | Satisfies `jev_ai_status_allowed` check constraint |
| `model_id` | `result.model_id` | Populated from runtime response or configured client `model_id` |
| `endpoint_label` | `"lm_studio_local"` | Default on `JevAIRun` and `JevStatusResponse` |
| `prompt_version` | `result.prompt_version` | Default `"jev-v3.0.0"` |
| `input_digest_sha256` | `result.input_digest` | 64-char SHA-256 hex digest over canonical safe context |
| `output_digest_sha256` | `result.output_digest` | 64-char SHA-256 hex digest over canonical workflow result |
| `context_summary` | `result.evidence_breakdown` / `result.detector_summary` / `result.deterministic_diff` | Safe allowlisted JSON summary (zero raw PE, vectors, secrets, or blind data) |
| `response_text` | `result.summary` / `result.recommended_analyst_action` / `result.comparison_summary` / `result.markdown_content` | Advisory text / Markdown report |
| `latency_ms` | `result.latency_ms` | Float milliseconds (`0.0` for deterministic-only workflows) |
| `error_code` | `None` on success; `classify_jev_failure(exc).error_code` on failure | Canonical `XS_AI_*` code |
| `error_message` | `None` on success; `classify_jev_failure(exc).message` on failure | Redacted via `redact_sensitive_text` |

## 4. Canonical Failure Classification Contract (`classify_jev_failure`)

`x_sentinel.jev_ai.classify_jev_failure(exc)` provides a single deterministic mapping for `BE-13` route handlers and persistence hooks:

| Exception Class | `error_code` | `db_status` (`JevAIRun.status`) | Recommended HTTP Status | `retryable` |
| :--- | :--- | :--- | :---: | :---: |
| `JevAIDisabledError` | `XS_AI_DISABLED` | `blocked` | `503 Service Unavailable` | `False` |
| `JevAITimeout` | `XS_AI_TIMEOUT` | `failed` | `504 Gateway Timeout` | `True` |
| `JevContextBlocked` (including `JevForbiddenKeyError`, `JevBlindDataBlocked`, `JevContextSizeExceeded`, `JevAllowlistViolation`, `JevPromptInjectionBlocked`, `JevAuthorityViolation`) | `XS_AI_CONTEXT_BLOCKED` | `blocked` | `422 Unprocessable Entity` | `False` |
| `JevResponseValidationError`, `JevIncompleteDistributionError`, `JevAIResponseError` | `XS_AI_RESPONSE_INVALID` | `failed` | `502 Bad Gateway` | `False` |
| `JevAIConnectionError`, `JevAIHTTPError`, `JevAIUnavailable`, `JevAIConfigurationError` | `XS_AI_UNAVAILABLE` | `failed` | `503 Service Unavailable` | `True` (network/HTTP) / `False` (config) |

## 5. Phase P6 — BE-13 HANDOFF CONTRACT MATRIX

| BE-13 Endpoint (`10_API_CONTRACT.md` & `jev_ai_openapi_fragment.yaml`) | HTTP Method & Path | Orchestrator / Status Entrypoint | Request Schema | Response Schema & Envelope | Persistence & Audit Action |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Runtime Status** | `GET /v1/ai/status` | `build_jev_status(settings)` | Query/Header (Auth optional in local mode) | `JevStatusResponse` (`enabled`, `available`, `status`, `model_id`, `endpoint_label`, `advisory_only=True`) | Read-only status probe (`0` network calls when disabled) |
| **Advisory Workflows (`explain` / `triage` / `compare` / `report`)** | `POST /v1/ai/explain` | `JevAIOrchestrator.explain()` / `.triage()` / `.compare()` / `.report()` / `.run()` | `JevRequest` (`mode`, `analysis_id`, `compare_analysis_id`, `question`, `context`) | `ExplainResult` / `TriageResult` / `CompareResult` / `ReportResult` / `JevResponse` + `run_id` (`advisory_only=True`) | Insert `JevAIRun` (`completed` / `failed` / `blocked`) + `AuditEvent` (`jev_ai.<mode>.<status>`) |
| **Run Retrieval** | `GET /v1/ai/runs/{run_id}` | DB query on `JevAIRun` by `id` | Path param `run_id: UUID` | Stored `JevAIRun` metadata, digests, `context_summary`, `response_text`, `advisory_only=True` | Read-only lookup (`404 XS_NOT_FOUND` if missing) |
| **Analyst Feedback** | `POST /v1/ai/runs/{run_id}/feedback` | DB insert into `JevAIFeedback` | `rating` (`1..5`), `label` (`helpful` / `not_helpful` / `incorrect` / `unsafe` / `unclear`), `comment` | Created `JevAIFeedback` metadata (`feedback_id`, `jev_ai_run_id`, `created_at`) | Verify `JevAIRun` exists, redact `comment`, insert `JevAIFeedback` + `AuditEvent` (`jev_ai.feedback.recorded`) |
