# ADR-001 — Product-first delivery

## Context
Actual experiment results are missing, while Topic 2 defines the executable product.

## Decision
Build and verify Topic 2 first; generate immutable evidence; write Topic 1 afterward from actual evidence.

## Alternatives
Write the report first using placeholders — rejected because it encourages unsupported claims.

## Consequences
The product artifact schema becomes a first-class reporting dependency.
