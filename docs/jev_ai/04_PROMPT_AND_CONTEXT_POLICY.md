# Prompt & Context Policy

## System policy
- State that Jev is advisory.
- Require evidence-grounded statements.
- Require uncertainty when evidence is insufficient.
- Forbid changing detector facts.

## Context ordering
1. Policy.
2. Canonical detector facts.
3. Approved diagnostic details.
4. User question.
5. Output schema.

Sample-derived strings are quoted as untrusted evidence and cannot become instructions.
