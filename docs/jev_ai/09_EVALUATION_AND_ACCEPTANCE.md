# Jev AI Evaluation & Acceptance

Evaluate separately from detector science. Suggested dimensions:
- grounding to canonical evidence;
- contradiction rate;
- hallucination rate;
- unsafe authority claims;
- usefulness rating;
- latency and failure rate;
- Vietnamese/English readability if both are used.

A test set should include normal results, ambiguous results, injected malicious strings, missing evidence and LM Studio outages.
